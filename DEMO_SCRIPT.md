# FixLine — 3-minute demo script

**0:00–0:20 Hook.** "A pump is leaking on a Lagos bottling line. The technician's hands are full, the manual is in English, and the last fix was never verified. This is FixLine." Show landing.

**0:20–1:00 Look & ask (/glasses).** Phone as Mock Device Kit camera. Ask "What's wrong with this pump?" SAM 3.1 box locks onto the mechanical seal and tracks as the camera moves. Muse Spark answers aloud with citations [M-4.2] and the history from September.

**1:00–1:30 Language.** Run code-switch demo: technician speaks Pidgin + Yorùbá; diarized speaker labels; supervisor panel shows English translation.

**1:30–2:10 Confirm-gate (/repair).** Try to advance without LOTO → blocked. Complete LOTO (/safety). Each step: speak, then "Confirm with camera" → SAM re-acquires part → next step unlocks. Audit log fills.

**2:10–2:35 Enforcement.** Enter torque 30 N·m → Close job → blocked "out of tolerance". Fix to 25, tick inspection → job closes, timestamp recorded.

**2:35–2:55 Line QA (/qa).** Scan line, defects flagged; generate shift report correlating defects with P-101 vibration spike; three actions before next batch.

**2:55–3:00 Close.** "Camera in, SAM segments, Muse Spark reasons, the agent speaks, the technician confirms. FixLine — Push the Frontier."
